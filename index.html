Git & GitHub Commands

Your Complete Git Commands Cheat Sheet

1. Basic Commands

git --version
git init
git status
git log

2. Git Configuration

git config --global user.name "Your Name"
git config --global user.email "email@gmail.com"

3. Add & Commit

git add .
git add filename
git commit -m "Initial commit"

4. GitHub Push

git remote add origin URL
git branch -M main
git push -u origin main

5. Pull & Clone

git clone repository_URL
git pull origin main
git fetch

6. Branch Commands

git branch
git branch new-branch
git switch -c new-branch
git merge branch-name

7. Undo Commands

git restore filename
git reset filename
git revert HEAD

8. Stash Commands

git stash
git stash pop
git stash list
